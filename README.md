# Cinematic Systems

Cinematic screen simulation. Run simulated applets for hacking processes; useful for movie scenes.

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Existing applets

- Decryption applet
- File transfer applet
- Verificaton applet
